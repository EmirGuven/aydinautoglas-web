# How to add a new sector template

> Fully implemented in Phase 8 — `autoglass` (full DE/EN/TR content) and `generic-service`
> (lighter skeleton) both exist under `server/db/seed/templates/`.

1. Create `server/db/seed/templates/<sector-name>.ts` exporting a `seed<SectorName>Template()` function that calls the normal service-layer functions (`createPage`/`createBlock`, `createService`, `createLocation`, `createFaq`, `createTestimonial`, `createQuestion`/`createOption`/`createRule`, `createBlogCategory`/`createBlogPost`, `createMenuItem`, `setTheme`, `setSetting('general', ...)`) — never raw `db.insert`, so the same validation and slug-uniqueness rules apply as an admin editing content by hand. Provide content for every active language; a legal page's `seo` can set `noindex: true` for that locale. Skip `partners` — `logoMediaId` is a required media reference and a seed script has no image to upload.
2. Register it in both the `TEMPLATES` map in `server/db/seed/run.ts` (for `pnpm db:seed --template=<sector-name>`) and the `SECTOR_TEMPLATES`/`SEED_FNS` in `server/services/sector-template.service.ts` (for the admin "Apply template" screen) — the two entry points share the same seed function, so there's only one place the actual content lives.
3. The admin screen (`/admin/appearance/templates`, `owner`-only) already handles preview (name + description card), confirmation (`AdminConfirmDialog`), and backup: `applySectorTemplate()` snapshots every content table into `site_settings.lastTemplateBackup` (a single slot, not a history — see ADR-0011) before truncating them and running the new template's seed function. Add a template by editing the two maps in step 2; the screen picks it up automatically.
4. Verify: applying the template with `docker compose up` + `pnpm db:seed --template=<sector-name>` on a fresh database renders a fully working site in all configured languages, and applying it from the admin screen against a database that already has content correctly replaces that content (spot-check `site_settings.lastTemplateBackup` was written first).
